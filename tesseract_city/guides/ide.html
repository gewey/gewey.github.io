Overview: Why Keep Your Code Local?

An IDE (Integrated Development Environment) is the cockpit of your agentic operation. While consumer chatbots live in browser tabs, your game, your assets, your scripts, and your documentation must live locally on your filesystem.

If a cloud vendor changes terms, goes down, or revokes access, a web-only project is paralyzed. When your codebase is on your local machine under Git version control, you can point any agent, any extension, and any model at it at any time.

The Dedicated Drive Partition (e.g. V:/)

Before installing any tools, carve out a dedicated partition on your drive. 50GB is a comfortable minimum; 200GB is roomy and future-proof.

warning Why A Separate Partition?

Windows system folders (like $RECYCLE.BIN and System Volume Information) automatically generate at the root of every drive. If you try to make your whole C: drive a Git repo, Git will choke on system files. By creating a dedicated drive letter (e.g. V:\), your projects are cleanly quarantined.

The "Fire Containment" Strategy: Don't keep a single monstrous monolithic repo for everything. Structure your hubs into clean directories: 

V:\
├── __inuus__\            -> Visual SSOT, branding, websites (gewey.github.io)
├── __sentinus__\         -> Agent executive modules, task master, morning rituals
├── __terminus__\         -> Low-level lizard brain, hardware hooks, scripts
└── ExterminationNation\  -> Your game root, assets, code, and lore

If an experimental agent script causes a fire in one folder, the fire doesn't spread to your other projects.

VS Code (Visual Studio Code)

Visual Studio Code is the battle-tested champion of modern development. Lightweight, universally supported, and backed by thousands of extensions.

smart_toy Copilot Chat & Custom Models

VS Code comes with GitHub Copilot Chat out of the box, but you are not locked into OpenAI models. With recent updates, you can bring your own models (Claude 3.7 Sonnet, Gemini 2.5 Flash, etc.) directly into Copilot Chat or run alongside extensions like Cline.

Recommended VS Code Configuration:

  • Disable telemetry: Keep your local code quiet.
  • Install Material Icon Theme: Visual bandwidth matters when scanning 50+ files.
  • Configure Tasks (.vscode/tasks.json): Bind recurring agent commands and builds to keyboard shortcuts.

Google Antigravity IDE & Extension

Google Antigravity IDE is built specifically for autonomous agents from the ground up.

Unlike standard editors that treat AI as a sidebar autocomplete, Antigravity treats agents as first-class autonomous background workers. You can spawn multiple agents in parallel across separate projects, grant them terminal and browser subagent capabilities, and orchestrate complex tasks while you work on other files.

bolt The Antigravity IDE Extension

If you prefer staying in VS Code, you can install the Google Antigravity Extension to bring the exact same agent orchestration engine directly into your existing VS Code environment!

Bring Your Own Key (BYOK)

"Bring Your Own Key" is the modder's superpower. Instead of paying a flat $20–$40 fee to a single chatbot wrapper that throttles your messages, you generate raw API keys:

  • Google AI Studio Keys: High rate limits, blazing fast speeds on Gemini models.
  • Anthropic Keys: The gold standard for adversarial reasoning and critical architecture reviews.
  • DeepSeek / OpenRouter: Ultra-low token costs for background transformations and batch processing.

Feed these keys into your local IDE extensions (like Cline or Copilot BYOK) and swap engines based on what the current task demands.

Cline IDE & Extension Workflows

Cline started as an open-source autonomous coding extension for VS Code and has since evolved into its own dedicated IDE.

With features like Clinepass ($10/month), it gives you generous usage limits across mid-tier and open frontier models (like DeepSeek 4.1 Flash). Cline can create files, run terminal commands, execute tests, and self-correct when errors appear.
