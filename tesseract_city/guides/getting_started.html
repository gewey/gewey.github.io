01. The Mindset: You're Not A Coder, You're A Studio Director

When a friend asks "Do you use an agent?", they usually imagine opening a web chatbot, pasting a question, and copying whatever code comes back. That is consumer autocomplete.

An agent is an LLM + Tools + Persistent Memory + Local Filesystem Access. The Large Language Model (Gemini, Claude, DeepSeek) is simply the electricity in the brain. The agent is the entire autonomous entity you construct around that electricity.

lightbulb You are the Studio Lead

Never look down on "vibe coding." If you have big ideas and can articulate design, mechanics, and lore clearly, you are essentially the creative director of an indie studio. The models in your IDE and your lore vaults are your technical team. Your job is architecture, direction, and taste.

The Golden Rule of Model Sycophancy: Always cross-examine your architecture across multiple model families. Most frontier models are pathologically polite — like the Adoring Fan from Oblivion: "By Azura, by Azura, it's the Grand Champion!" Anthropic's Claude is the rare exception (he will roast your flawed logic to your face). Don't be the guy who thinks he invented new math because a single agreeable chatbot wouldn't tell him his formula was nonsense.

02. The Hardware & File Foundation: Keep It Local

The number one mistake beginners make is building their whole game or project inside some proprietary web interface that only that company's bot can see.

Keep your work local on your machine. If the cloud goes down, your code, your assets, and your project history must remain 100% yours.

storage
The Dedicated Drive Partition (e.g. V:/) Separate your agentic workspace from your Windows OS drive to contain fires.
Read Partition Guide ➔

Create a dedicated 50GB–200GB partition (I use a 200GB V:/ drive). Why? Because Windows operating system folders like $RECYCLE.BIN and System Volume Information will pollute git root syncs. By giving your projects their own drive letter, your workspace remains surgical, modular, and safe.

The Two File Formats You Must Devote Yourself To:

  • Markdown (.md): The lovechild of .txt and .html. It is the universal language of AI instructions (See Markdown Scrapers). Your instruction files (like AGENTS.md, GEMINI.md, or .clinerules) should live in Markdown.
  • JSON (.json): How AI actually organizes structured thoughts. Think of JSON as a relational database printed on clean paper. Agents read and write it natively.

03. Picking Your IDE & The BYOK Philosophy

An IDE (Integrated Development Environment) is basically Notepad on steroids for code. This is where your autonomous agents live, edit files, run tests, and manage your repositories.

terminal
IDE Deep Dive: VS Code vs. Google Antigravity Detailed comparison of setup, agent configurations, and workspace layouts.
Explore IDE Guide ➔

We primarily operate between two powerhouses:

  • VS Code (Visual Studio Code): The indestructible industry standard. Paired with GitHub Copilot Chat or extensions like Cline, it gives you a clean canvas where you can swap models on the fly.
  • Google Antigravity IDE: Designed specifically for multi-agent parallel workflows. Orchestrates multiple autonomous subagents running tasks across projects without losing context.
key BYOK: Bring Your Own Key

Instead of being locked into a single subscription vendor, look for tools that support BYOK. You generate an API key from Google AI Studio, Anthropic, or OpenAI, plug it directly into your IDE extension, and only pay for the raw electricity you consume.

04. IDE Extensions & Local Models (Bang For Your Buck)

How do you get maximum horsepower without going bankrupt on frontier token rates? You balance frontier models with local engines.

The Top Subscriptions & Runtimes:

  • Google AI Pro ($20/mo): The absolute highest bang-for-your-buck package. Gives you access to Gemini Advanced, Google AI Studio limits, NotebookLM, and Antigravity IDE — essentially five separate usage pools on a single account.
  • Ollama (Free Local Models): Runs open-source weights locally on your own GPU/CPU. When doing repetitive, cheap code transforms or formatting where frontier tokens are overkill, run DeepSeek 4.1 Flash or Llama locally for $0.
  • Cline & Clinepass ($10/mo): An autonomous coding extension (and now standalone IDE) with built-in task trees, terminal execution, and mid-tier model routing.

05. Defeating AI Amnesia: The Lore Team & Shared Memory

Every episode of The Simpsons ends, and the next episode resets to the status quo like nothing happened. AI models suffer from the exact same amnesia. If you don't build persistent memory, you will waste hours explaining your codebase from scratch every morning.

chrome_reader_mode
Chrome Extensions: Markdown Scrapers & Transcript Exporters Snapshotting live /docs and feeding fresh SDK references into your prompts.
See Chrome Tools ➔

The 3 Weapons to Win Against Amnesia:

  1. NotebookLM as your Lore Vault: Export every brainstorming chat transcript as a .md file using a Chat Exporter Extension. Dump those transcripts into a single Google Notebook. NotebookLM becomes your dedicated lore team, changelog, and design historian.
  2. Snapshot Live Docs to Markdown: Models are trained on cutoff dates from last year. Never let an agent guess modern syntax. Use a browser extension to take Markdown snapshots of live SDK/API reference pages, then feed them directly into your agent's prompt.
  3. Persistent Memory Vectors (Mem0 & MCP): Hook your agents into Model Context Protocol (MCP) servers and memory layers so all your IDE extensions draw from the same continuous knowledge pool.

06. Co-Op Dev & Git Hygiene: Press X to Party Up

Stop emailing .zip files over Discord. If you are serious about game dev or software creation, Git is your safety rope and co-op bridge.

group_work
Co-Op Guide: Branching, Collabs & Remote Sync How to party up with fellow developers and keep your code indestructible.
Party Up Guide ➔

Keep private repositories on GitHub. When you make a mistake, Git allows you to revert single files or entire builds back to any savepoint in history. And when a buddy wants to jump in and help, you simply add them as a repository collaborator — you both pull, branch, and push without ever corrupting each other's work.
