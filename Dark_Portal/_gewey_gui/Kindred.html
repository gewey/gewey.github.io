The hunter thread

Four of the nine are hunters: 90 Beast Mastery, 23 Survival, 18 Beast Mastery, 10 Marksmanship. One class across four races (Dracthyr, Worgen, Undead, Zandalari Troll) and four specs — the only continuous line in the family. Everything else changed.

The undeath stint, confirmed by a machine

Tandu on Hyjal is an 18 Undead Beast Mastery Hunter. That is the stint, still standing on a live server years after the fact — not a memory, a row. And it is a hunter: the vessel changed, the aim did not.

The blood-elf problem

Nine live characters. Zero blood elves. The armory has never once shown a Sin'dorei for this account, across every door this vault has opened. So the “always a blood elf” baseline cannot be measured — it is attested, and this page will not dress an attestation as a measurement. The armory can prove the vessels; it cannot prove the soul. What it does prove is that the soul kept rolling hunters.

The WCL wall changed shape this week

On 2026-11-20 the Warcraft Logs character URLs answered 200 with a 4,126 B body titled Human Verification. On 2026-11-25 the same URLs answer 403 with a 5,472–5,484 B body titled Just a moment.... Same wall, new paint — and a naive status check would have called the first one a success. Record status, size and title together or the wall disappears into a green tick.

Raider.IO is four years behind on an alt

Tantrums answers the Raider.IO API with last_crawled_at 2022-08-04, ilvl 107, 18,240 achievement points, 0/9 in a Midnight tier. The armory, read today, says 56 Zandalari Troll Enhancement Shaman, 296 ilvl. Raider.IO is not wrong; it is stale by four years on a character nobody feeds. Use it for the main, read the armory for the family.

Search engines index nothing

Three engines, ten queries, zero rows. DuckDuckGo autocorrects Tandumonium to Tandemonium (the Steam game) and returns nothing else; Mojeek and Bing return no result markup at all. The name is unique enough to be unambiguous and obscure enough to be unindexed — which is why the record has to live on disk.

The loadout receipt

While the armory was being swept, the client’s own config logs were counted. Across AccountData.log (10,613 lines) and AccountData.log.old (38,454 lines) the same three lines appear 41 times each:

/btwl a Tandu
/btwl a Raid
/btwl a PvP

That is BtWLoadouts being asked to apply three saved gear sets, over and over, re-saving the account cache each time. The set named Tandu is still live in the engine: the old handle is not a history entry, it is a button the game presses. Three sets, 41 saves, one name that outlived its character.
