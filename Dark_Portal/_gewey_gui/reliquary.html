The Macro Language

105 macro blocks, 57 distinct names, and not one of them is called "Bear Trap". The naming is a cipher that survived three realms and at least two classes: sigil first, payload second.

Sigil census across all five characters that carry macros.
SigilBlocksMeaning, as written on the bar Examples

=4key-shape twin — the same action bound to the same physical key on a second layout = · = - Pal
plain70single-key ergonomics: letter, digit or symbol only, so the bar reads as a keyboard Q E R T Z F G 1 2 3 4 5 6 `

Why the names are shaped like that

The sigil is a type tag the eye parses before the icon loads: # means "a spell lives here"; $ means "a macro family anchor" ($Loot, $Dstry, $Fish, $Targeting); ! means "a sequence token" (!STOP, !1, !2222, !SND, !DR2); / means "a slash command" (/13, /6, /TSM, /SUF, /fstk); @ means "a mode switch" (@PvP, @Raid, @NO RAID); ~ marks an item (~skull).

The paladin on Shadowsong uses the same cipher with a suffix: #n1 - Pal through Z - Pal. Twenty-two blocks, one realm older, same law. That is the clearest proof this station holds that the macro language is a personal convention rather than an addon's output: no addon would invent - Pal. Only the same hands would.
