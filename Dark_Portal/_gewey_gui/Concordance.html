Only exact and prefix matches are claimed. A prefix match means the shard hyphenated a name the retail client had always spelled as one word (Kar-Kol against Karkol); the page says so rather than pretending the spelling is identical.

The decade the disk does not hold

Neither install contains a single file older than the retail client that wrote it. There is no 2008 folder, no Wrath-era config, no Cataclysm cache: the auth server has never replayed an old character tree onto a new machine. The 2008–2018 stretch is carried entirely by Origins (what the archive never saw) and Legacy (the handles and the guild windows).

Guild tenure rule, restated because this wing touches guild history: <Gehenna> is admissible only inside the 2019–2020 Battle for Azeroth window (WCL guild 7287); <Theorycrafters> only on Thrall-US and Hyjal-US. Pre-tenure Wayback captures of the guild page are never recorded, not here and not in any other wing.

Method & limits

One read-only walk of both WTF trees. A folder is a character; a file is a file; the newest mtime is the newest mtime. No inference is drawn from an addon name about what a character did.

Research/_local/_concordance_build.py   -> this page
Research/_raw/concordance_20261120.json  -> the same numbers, machine-readable

Limits, stated plainly. (1) The retail account shows 54 folders; the realm a character plays on is read from the folder it sits in, not from the server. (2) A ghost shell proves only that the folder was written, never that the character was deleted. (3) Prefix bridging is a spelling judgement and is labelled as one. (4) Nothing on this page is live — re-run the builder to refresh it.
