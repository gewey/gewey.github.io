Method & Limits

Every report code on raidlogs.html was fetched through api.wipefest.gg/report/<code> and every one of the 470 answered; the failures list is empty. Everything above is recomputed from the friendlies array of those payloads — no figure is estimated and no name is invented. Names keep the encoding the API returned; where a byte did not decode, the replacement character is shown rather than a guess.

The name tape is the first and last report in which each of the three names appears as a friendly. It is a window, not a timestamp: the gap between two names is a count of days with no capture, so the rename happened inside that gap and not necessarily on its first or last day.

A name in a pull is not an identity. Eight names below also exist as character folders under _retail_\WTF\Account\QUAZZARR, which is corroboration, not proof that a given pull was that toon. The other 8,393 are only names the logs remember.

Guild tenure: this page asserts no guild membership at all. The only in-window guild record is the 2019 Battle for Azeroth <Gehenna> era (Warcraft Logs guild 7287) already recorded elsewhere; no pre-2019 capture is used or re-added here.
