Method. Generated, not hand-typed. chassis_build.py reads every Account|Character Edit Mode Data Loading|Saving line in Logs\EditMode.log and Logs\EditMode.log.old, pairs each with the Data: line that follows it, then slices that blob on the layout markers to recover each named layout and its <anchor> <x> <y> -1 frame records. Declared and parsed slot counts are compared for all three layouts (exact match) so a grammar drift shows up as a mismatch instead of a wrong page. Log stamps carry no year or zone; the builder assumes 2026 and local time, the same convention as heartbeat_extract.py.
