What The Walls Mean

Warcraft Logs is not scrapable from here. Both the retail and the classic guild doors answer 200 with a human-verification shell, so any WCL work in this corpus has to go through the Wipefest report API (which answers) or a person opening the page. That is the operative constraint for every future raid-log pass.

The archive holds no capture of these pages. The availability API answers 200 and reports zero snapshots for the guild page and the character page, and the CDX index throttles to 429. The 2019 Battle for Azeroth era cannot be recovered from the Wayback Machine by this route, which is also why no pre-2019 capture is ever cited on this site.

Wowhead blocks programmatic reads. Every one of the 170 faction probes answered 403. That is why a standings table keeps its faction names as text: a link nobody can verify is worse than no link.

The search engines cannot spell it. Bing answers 200 and returns the Steam game Tandemonium for every quoted variant; Google answers a shell with zero parsed results; DuckDuckGo answers 202; Mojeek answers 200 with nothing. YouTube returns one video for the exact name and it is somebody else's footage. An eighteen-year character with a unique name is still invisible to web search, which is worth knowing before another pass is spent on it.

The Name We Cannot Claim

The account holds a Tankard folder on Hyjal, not on Shadowsong, so this record is not attributed to the family anywhere in this corpus. It is listed because a name collision is a fact worth recording, not because the identity is proven.

The same rule applies to Tantrums-Thrall: the account has no Thrall folder by that name. Only Tantrums-Hyjal matches a folder the account actually holds.

Method & Limits

One GET per door with a desktop user agent and a fifteen second timeout; status, byte count and verdict written to Research/_raw/doors_register_20261125.json (gitignored) before this page was built, so the table is a transcription and not a recollection. Nothing was submitted, posted or logged in to. Where a door answered 200 with a bot challenge instead of a record, the verdict says so rather than reading the 200 as success.

Tenure rule honoured: no guild membership is asserted here. The only in-window guild record remains the 2019 Battle for Azeroth <Gehenna> era (Warcraft Logs guild 7287) already carried on legacy.html; the Raider.IO guild probes for Gehenna and Theorycrafters both answer 400 and are reported as such.
