Three walls, three causes

Warcraft Logs — 403

Character and guild endpoints both refuse a plain client. This is a policy wall. The reports themselves are not lost: the 470-report vault on Raid Logs was harvested through the uploader's own pages before the policy tightened.

WoWProgress — 403

The live guild page now challenges every request. The archived copies still exist — archive.org's availability API confirmed the 2019 snapshot in 297 bytes.

Wayback — 429

CDX and capture bodies both rate-limit this host. The index was read on a previous pass; the bodies were not. The archive is throttled, never empty.

The one clean proof: archive.org/wayback/available?url=wowprogress.com/guild/us/borean-tundra/Gehenna returned 200, 297 bytes, closest snapshot 20190819150850, status 200, available true. That is the API confirming the capture exists without touching the throttled body endpoint.

Re-run this sweep

Six requests, no key. Run it from anywhere; only status and size are kept.

$ua = 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/124.0'
foreach ($u in @(
  'https://raider.io/characters/us/hyjal/Tandumonium',
  'https://worldofwarcraft.blizzard.com/en-us/character/us/hyjal/tandumonium',
  'https://www.warcraftlogs.com/character/us/hyjal/Tandumonium',
  'https://www.wipefest.gg/guild/7287',
  'https://www.wowprogress.com/guild/us/borean-tundra/Gehenna',
  'http://archive.org/wayback/available?url=wowprogress.com/guild/us/borean-tundra/Gehenna'
)) {
  try {
    $r = Invoke-WebRequest $u -UserAgent $ua -TimeoutSec 12 -UseBasicParsing
    "$($r.StatusCode)`t$($r.Content.Length)`t$u"
  } catch {
    "$([int]$_.Exception.Response.StatusCode)`twall`t$u"
  }
}

What the new route is worth. api.wipefest.gg answers with no key and no bot wall, and it carries the same metadata WCL hides: report owner, start/end, boss, zone, difficulty, raid size, kill flag. It is how the 470-report vault was read. What it will not do is list a guild's reports — that one query exceeds the host's own complexity ceiling, which is a limit of the service, not evidence about the record.

Negative, upgraded. The earlier ledger said the WCL wall was "a policy wall". This pass proves it is stronger than that: a full browser with JavaScript, cookies and twelve seconds of patience still gets the challenge page. Stop spending sweeps on it. The guild-door route above is the one that pays.
