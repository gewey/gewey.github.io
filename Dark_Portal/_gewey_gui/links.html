These are not documents; they are questions. Each returns raw JSON from the Internet Archive's CDX index, which is the only place a deleted 2010 character page could still be hiding. Open one in a tab and look for a non-empty array.

  • builder warcraftlogs · guild 7287
  • builder battle.net armory · shadowsong · tand* — never swept before 2026-11-10

Prefer the lighter endpoint when CDX is flapping: http://archive.org/wayback/available?url=<url> answers in one second and tells you whether any snapshot exists. That is how the 2015 Battle.net guild capture was found on 2026-11-10.
