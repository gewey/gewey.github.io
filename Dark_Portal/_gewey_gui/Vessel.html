The Vessel — the account file that outlives the character

A character is a vessel: it is renamed, rerolled, race-changed, deleted, restored. What sits underneath it is not. AccountData.log is the client's own persistence dump — account-wide settings, the bind map, the macro records, the Edit Mode layouts — and every slot in it carries a Server Save Time stamp. Read the stamps in order and the account draws its own column of memory, from 2018-09-06 to 2026-11-05, with the silences in between measured to the day.

The only name in the file

The account tape is almost perfectly impersonal: no character names, no realm names, no guild names. Two strings break that silence.

41copies of one macro body, both rotations

The macro record slot contains a macro whose body is /btwl a Tandu followed by /run SetTracking(10, true). The account file does not know the character's name — it knows a command that targets it.

22occurrences of the name Gewey!!

The Edit Mode slot's first named layout block opens 7 Gewey!! 52 and anchors frames such as MainActionBar and MainStatusTrackingBarContainer. It is the same layout name the Forever client logs in Chassis — one naming habit, two clients.

A name-family sweep also finds 41 case-insensitive hits for tandu across both rotations; every one resolves to the macro body above, not to a roster or a saved character key. That is why the page cites the macro, not the name.

What this tape cannot tell you

It has no character names, no realm names and no guild names. It does not record playtime, kills or quests. It only proves that a scope was written on a date — and it proves that on both clients' terms, not mine. The 2018-09-06 stamp is the oldest dated thing in the retail tree, but the retail tree itself was reinstalled in 2026; the stamp survived the reinstall inside the account data, which is the whole point.

Tenure rule: nothing on this page attaches a guild to a year. The guild matrix lives in Tenure and Legacy, scoped to the eras the account can actually prove.
