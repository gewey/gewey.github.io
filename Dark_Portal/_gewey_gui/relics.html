The Quest Ledger

The receipt nobody can fake

BtWQuests.lua stores a boolean for every quest a character has ever turned in. It is not a score, not an achievement, not a screenshot: it is the client's own completion table, written as you play and never pruned. The Dracthyr hunter carries 13,046 of them.

Two level-10 alts are tracked beside him — a Vulpera (788 quests) and a Harronir (783) — which is how we know the file follows the account, not just the main.

Read the bands carefully

Quest ids are allocated roughly in expansion order, so an id band is a proxy for the era a quest shipped in, not proof of when it was completed. A Classic-band quest can be finished tomorrow. What the ledger proves is breadth: this character has walked every expansion's quest chain, not one.

Seams are fuzzy by a few hundred ids, and holiday or removed content can sit outside its era. Treat the table as shape, not arithmetic.

Four Exhibits

Rachel Ray the scream

The macro the persona was built on: one button that pops every offensive cooldown and both trinkets at once. It is named for the television host on purpose — the sound is the point. The in-raid joke about yelling to force focus is not a joke in this file; it is a binding.

#showtooltip wailing arrow
/use aspect of the wild
/use 13
/use 14
/use wailing arrow
/use [@player] Sack of Spectral Spiders

@Raid loadout switch

One keystroke swaps the whole interface posture: apply the Raid loadout, disable every addon profile, reload on right-click. The /btwl a Raid line is the only surviving reference to the loadout manager's own set naming.

The Wardrobe

“Marx” — the saved set

BtWLoadouts keeps equipment sets by name. The main has exactly two: Marx (eleven saved slots) and an empty ST placeholder. The set is a photograph of a real outfit, saved at some point in Dragonflight-era gearing and never overwritten.

Item ids are stable; open one on Wowhead to see the actual piece. Cyrce's Circlet appears three times because the ring's socket variants are saved separately — not a bug in the save.

The Mount Stable

98 mounts, 193 summons

LiteMount.lua counts every summon per mount id. The roster is wide — 98 distinct mounts out of 193 total summons — which means the hunter cycles rather than camps one favourite. There is no saved-favourites list in the file, only the counts.

Caveat: LiteMount was installed on this client in 2026, so these counts describe current habits, not a lifetime of travel. They are still the only machine-readable mount record on disk.

Forty-five ghost shells

Of the 54 folders, only 9 contain a character anybody played. The other 45 hold a single AddOns.txt stamped 2026-09-16 18:31:44 by a bulk copy — name reservations and mules that never wrote a second file.

That asymmetry is the honest shape of a long-lived account: a handful of characters accumulate a life, and the rest are placeholders waiting for a story. Full per-toon evidence on Roster.

Method & Honesty

Read-only. The extractor walks WTF\Account\QUAZZARR, Interface\AddOns, Screenshots, Errors and Logs. It opens files for reading and writes its JSON to Research\_raw\retail_relics.json inside Dark_Portal. No file under _retail_ is created, modified, or deleted.

What is solid: macro counts and bodies, per-character macro counts, quest completion counts, loadout items, mount summon counts, addon folder versions and authors, crash and screenshot timestamps, GUID prefixes. All of it is copied out of the files, not inferred.

What is a proxy: the era bands on the quest ledger. Quest ids are allocated roughly in expansion order; the seams are fuzzy and holiday content does not obey them. The ledger proves breadth, not dates.

What this page does not claim: that any of these artifacts date back to 2008. The retail install on this machine is a 2026 client; the 2008–2016 record lives in the Armory reputation fossil (Dynasty), the Warcraft Logs vault (Raid Logs), and the era ledger (Eras).
