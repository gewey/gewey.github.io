How to read a refusal

200 is not success

Warcraft Logs answers every character URL with a 4,126-byte human verification shell and a 200. Four character URLs and one guild URL returned byte-identical bodies — that is the tell.

A 400 is a receipt

The Raider.IO armory answered 400 — could not find requested character for Tandu on four realms and Tandieu on four realms. That is not a network fault; it is the door confirming the name is retired.

429 means ask later, not never

Wayback’s CDX index rate-limits hard. Its availability endpoint still answers, which is how the census finding on Witnesses was made at all today.

403 is a wall, not a verdict

WowProgress, Warcraft Movies, Reddit’s search JSON, Wowhead user pages and WowDB all refuse this client. None of them is proven empty — only unreadable from here.
