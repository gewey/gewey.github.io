The Strata — what the shells remember

A character folder is what is left after the soul leaves: an addon load list, a macro cache, and — if the shell was ever played long enough to save — a CVar tape. Fifty-four of them sit in the retail account. Nine kept a tape. Read the tapes in order and the install dates itself: splash 94, 95, 96; one shell still holding a Shadowlands covenant record; a camera distance set in 2018 and never touched again. Then ask the armory which of the fifty-four still answers. Twelve do.

The CVar tape

Nine shells kept a config-cache.wtf. Nobody had read them. Each line is a setting the shell held at its last save, and a few of them are clocks: latestSplashScreen counts how many splash screens the install had shown, lastRenownForCovenant1..4 is a Shadowlands covenant record, and newPvpSeason / newMythicPlusSeason stamp the last season the shell noticed. EJLootClass is the class the loot window was set to — the body's class, written by Blizzard rather than by an addon.

Addon ghosts

Every AddOns.txt is the load list of the last session. Six names in those lists have no folder in Interface\AddOns today: the shells remember an interface the install no longer has. Two of the six are Blizzard-internal names that never had folders, which is itself the point — the load list is a whole interface, not just third-party addons.

Method & receipts

Read-only throughout. The game install was never written to; the two JSON payloads live under Dark_Portal/Research/_raw/ and are gitignored, and this page carries every figure baked in, so no reader ever fetches them.

scan : _retail_\WTF\Account\QUAZZARR\<Realm>\<Character>\
        AddOns.txt  macros-cache.txt  config-cache.wtf  SavedVariables\*
doors : raider.io/api/v1/characters/profile
        region=us&realm=<realm>&name=<name>&fields=gear,guild
        one GET per shell, 6 workers, no auth, no cookies
build : Research/_local/_strata_scan.py   -> retail_strata_20261125.json
        Research/_local/_strata_doors.py  -> retail_strata_doors_20261125.json
        Research/_local/_strata_build.py  -> _gewey_gui/Strata.html
Tenure gate. <Gehenna> is admissible for the 2018-10 → 2020-10 BfA window on Shadowsong / Borean Tundra (WCL guild 7287); <Theorycrafters> for Thrall-US and Hyjal-US. The 24 pre-2019 Wayback captures of <Gehenna> are guild history, not membership, and are never recorded here. See Tenure.
