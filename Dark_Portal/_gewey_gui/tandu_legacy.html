Macro DNA — the #N* convention

98account macros
105character macro blocks
5toons with personal bars
0character-scoped macros

The account library is the oldest artifact on the install: WTF\Account\QUAZZARR\macros-cache.txt, sixteen kilobytes, ninety-eight blocks. The naming is the fingerprint — not the bodies. Every block is VER 3 <id> "<name>" "<icon>", and the names cluster:

[!]   !!!!, !!!!!, !!!!!!, !!Abandon Quests, !!Melee template
[!]   !/btwl, !1, !2222, !3333, !4444         -> scratch pad, never pruned
[#N]  #N*, #N+, #N-, #N1, #N2, #N5, #N6, #N8, #N9
[bar] 1, 2, 3, 4 ...                          -> slot-numbered utilities

Three naming families, one habit: ! for "never delete this, it is a scratch macro", #N for the numbered utility set that every hunter shares, and bare slot numbers for one-offs. The #N cluster is byte-identical across four characters, which means it was copied by hand from toon to toon rather than rebuilt — the macro bar is the only thing in WTF that is deliberately portable.

The Wayback record — the two tenure-era captures

Every earlier pass recorded the Wayback CDX endpoint as hanging past twenty seconds and wrote the archive off. It does not hang; it is slow and throttled. A single plain request with a real user agent returns the full capture index for the one page that matters: wowprogress.com/guild/us/borean-tundra/Gehenna. The index holds 26 captures, but only two of them fall inside the <Gehenna> tenure window. Only those two are listed. Everything from 2009–2016 predates the tenure and is not Tandu's history, so it is not recorded.

Honest limits. The capture index resolved; the page bodies did not, on this pass — the archive answered HTTP 429 to every follow-up request from this host. One body was read far enough to confirm the shell ("WoW Guild Gehenna @ Borean Tundra :: WoWProgress"), then throttling resumed. The 2019 body is the one worth retrying later: it is the only capture inside the documented <Gehenna> tenure window.

Warcraft Logs remains a wall, not an absence: warcraftlogs.com/character/us/hyjal/tandumonium answers 403 to a plain request, and the guild page answers with the 3.7 KB Cloudflare "Human Verification" body — a 200 that contains no record. No archived capture of any Tandu WCL character page exists in the CDX index (checked across four realms). That is a real negative result, and it is recorded here so nobody re-runs the same sweep expecting a different answer.
