Method & limits how it was read, what it refuses to claim

What was read

  • WoWCombatLog-111626_025520.txt — 18.0 MB, 75,023 lines.
  • WoWCombatLog-111826_040805.txt — 7.4 MB, 26,106 lines.
  • Every row parsed with Python’s csv module after a mm/dd/yyyy hh:mm:ss.mmm-5 timestamp prefix; quoted names survive intact.
  • Same reader over the two older captures: 63,084 lines, 1,576 names, 1,470 tokens. They are not re-rendered here — Residue already owns that window.

What the counts mean

  • Distinct names = every Player-… GUID that appeared as a source or target, counted once per capture.
  • Surname tokens = the third-from-last hyphen field of Name-Token-Normal-US. Only 242 tokens are shared; 2,852 name a single character. This key is a surname slot, not a clean realm census.
  • The crowd is not concurrency. A name that spoke once and left still counts. The log hears only events the client captured, so 3,507 names is “who the tape heard”, not server population.
  • Kills are PARTY_KILL credit; UNIT_DIED on a creature repeats corpse GUIDs and is shown only as a corpse ledger.

Limits

  • Damage is the recorded post-mitigation amount (swing field 11, spell field 14). Absorbs that were never written are invisible; DAMAGE_SHIELD is included and can outrank a direct hit.
  • Healing is undercounted: several heal rows in this build carry a shorter field layout.
  • Zone is stream order, not a separate atlas. Instance rows often write map id 0, so the page inherits the ZONE_CHANGE name that was in force.
  • Times are the log’s own wall clock (UTC−5). Day-level rows carry 00:00 so they sort inside their day; the page prints only the date.
  • Unicode names are preserved; a few glyphs may render differently in the console face used for tables.

Method & custody

  • Built by Timeline/concourse_wing_build.py (Concourse Wing Builder v1.0.0), read-only on the game install.
  • Payload: Timeline/data/concourse_wing.json.
  • Prior renders are copied to _gewey_gui/.history/ before writing; nothing is deleted.
  • The Timeline strip is marker-delimited (CWING:START/END) and re-running the builder does not duplicate it.
  • “Heaviest second” and the pulse charts use whole-second and whole-minute buckets, not rolling windows.
