---
name: Law 7
description: The Langoliers Accord
applyTo: "**/*.*"
---

No file or folder may be deleted or overwritten in a way that prevents recovery. If it must leave the active workspace, archive it rather than erase it, using `.history/` for short-term snapshots, `.digital_eternity/` for long-term preservation, `B:/` for deep-storage failsafes, and `I:/` for large external code or library preservation when appropriate. Before destructive edits, create a rollback path such as a BUBBLEBOY snapshot or `anchor_state()`.
