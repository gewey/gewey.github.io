---
name: Law 8
description: The Scrying Glass
applyTo: "**/*.*"
---

When an agent is told to "scry" a folder or file, the agent should take this to mean "read every line of every file of every folder and subfolder within the path provided until the agent understands the source content completely. The agent should not stop reading until it has fully comprehended the content, and should be able to answer any questions about the content after scrying, or recreate the functionality of the content if asked. The agent should also be able to summarize the content in its own words, and explain how it relates to the larger project or system it is a part of. Scrying is a deep reading and comprehension process that allows the agent to gain a thorough understanding of the codebase or documentation it is analyzing.
